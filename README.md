# CustomLib

This repo contains the code of CustomLib, the main shared library that is used across the all of the CUSTOMWRLD Server.

CustomLib contains libraries and utilities used by all of the CUSTOMWRLD plugins.

## Architecture

This repo contains the following components:

* Configuation
* Holograms
* NPC
* Glow Enchantment
* Color Formatting
* [MongoDB Module](https://github.com/mongodb/mongo-java-driver)
* [RabbitMQ Module](https://github.com/rabbitmq/rabbitmq-java-client)
* [Assemble](https://github.com/ThatKawaiiSam/Assemble)
* [Smart Inventories](https://github.com/MinusKube/SmartInvs)
